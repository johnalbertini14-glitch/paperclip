## Technical Implementation

### Encryption Strategy
```
On Write (Token Refresh):
  1. Generate new tokens via provider (OAuth service)
  2. Store in updated_fields dict
  3. encrypt_credentials(updated_fields) — encrypt all sensitive fields
  4. Save encrypted_fields to MongoDB

On Read (Any credential access):
  1. Fetch document from MongoDB
  2. decrypt_credentials(doc) — decrypt + fallback for plaintext
  3. Return fully decrypted document to application
```

### Backward Compatibility
- ✅ New code reads plaintext (fallback mode)
- ✅ New code writes encrypted
- ✅ Old plaintext continues to work unchanged
- ✅ Gradual migration possible (old + new coexist)
- ✅ Rollback possible (disable encrypt_credentials() calls)

### Security Properties
- **Algorithm**: Fernet (AES 128-bit + HMAC)
- **Key**: ENGAGEAI_SECRETBOX_KEY environment variable
- **Performance**: Negligible (crypto operations microseconds)
- **Scope**: Only `user_integrations` collection (where secrets are stored)
